# Documents & Policies

The Documents module is where your manuals, policies, and procedures live. Vissibl uses a clean, Notion-style editor that makes it easy to create and maintain your compliance documentation.

## The document editor

Vissibl's editor works like Notion — click anywhere to start typing, and use forward-slash commands to insert blocks like headings, tables, lists, and more.

### Using forward-slash commands

Type `/` anywhere in the editor to open the command menu. Common commands include:

* `/heading` — Insert a heading (H1, H2, H3)
* `/table` — Insert a table
* `/list` — Insert a bulleted or numbered list
* `/divider` — Insert a horizontal divider

### Copy-pasting from Word

You can paste content directly from Microsoft Word. Vissibl preserves most formatting including headings, bold/italic text, lists, and tables.

## Document lifecycle

Every document in Vissibl follows a structured lifecycle:

1. **Draft** — The document is being created or edited.
2. **Review** — The document has been submitted for review.
3. **Approve** — One or more approvers sign off on the document.
4. **Publish** — The document is locked and visible to your team.

## Approval workflows

Set up approval workflows to route documents through the right people before publishing:

* Assign one or more approvers to a document.
* Approvers receive a notification and can approve or request changes.
* Once all approvers sign off, the document can be published.

## Reading confirmations

Assign policy sign-offs to ensure your team has read and acknowledged key documents. Users will be prompted to confirm they've read the document.

## Version history

Every published document maintains a full version history. You can:

* View previous versions and compare changes.
* See who made each change and when.
* Revert to a previous version if needed.

## Exporting documents

Export any document as **PDF** or **DOCX** for sharing outside of Vissibl or for audit evidence packs.
