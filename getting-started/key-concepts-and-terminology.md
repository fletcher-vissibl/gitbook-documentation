# Key Concepts & Terminology

| Term | What it means in Vissibl |
| --- | --- |
| **Vault** | Your secure file store. Upload existing documents here — they become searchable and feed Vissi's AI context. |
| **Documents** | Policies, procedures, and manuals you manage directly in Vissibl's editor. These go through a draft → review → approve → publish lifecycle. |
| **Gap Analysis** | An AI-driven assessment of your uploaded documents against your selected ISO framework(s). Shows what's present, what's missing, and what needs review. |
| **Register** | A structured table for tracking records (training, assets, interested parties, etc.). Fully customisable with different column types. |
| **Non-Conformity (NC)** | A deviation from a requirement — either from an audit finding, customer complaint, or internal observation. Tracked through to corrective action and closure. |
| **CAPA** | Corrective and Preventive Action — the structured response to a non-conformity. Includes root cause analysis, immediate actions, and long-term corrective actions. |
| **Risk Register** | A list of identified risks with likelihood/impact scoring, assigned owners, and treatment plans. |
| **Audit Readiness** | A status indicator showing whether your documentation and implementation evidence are sufficient to pass an audit for your selected framework(s). |
| **Framework** | The ISO standard(s) you're working towards — e.g., ISO 9001, ISO 14001, ISO 45001, or an integrated combination (IMS). |
| **IMS** | Integrated Management System — managing multiple ISO frameworks together, sharing common controls and documentation where clauses overlap. |
| **Vissi** | Vissibl's AI assistant. Answers compliance questions using your company's documents and context. |
