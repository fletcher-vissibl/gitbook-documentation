# Reviewing and Publishing Policies & Procedures

Your onboarding team imports your key documents into Vissibl's editor. Before they're visible to your team, you need to review and publish them.

## To review a document

1. Open the document from the **Documents** section.
2. Read through the content. If you're happy, you can publish it directly.
3. If changes are needed, edit using the Notion-style editor (see [The Document Editor](../platform-guide/documents-and-policies.md)).

## Publishing options

* **Direct publish** — You review it yourself and publish immediately. Good for straightforward documents where you're the sole decision-maker.
* **Approval workflow** — Route the document through one or more approvers before publishing. Useful when multiple stakeholders need to sign off.

{% hint style="info" %}
To use the approval workflow, you'll need other users added to your account first. If you're the only user, start by adding your team (see [Inviting Users](inviting-users.md)).
{% endhint %}

Once published, documents are locked (read-only) with full version history. Any future edits create a new draft version that goes through the same lifecycle.
