# Browser Compatibility

Vissibl is a web-based application that works best on modern browsers.

## Recommended browsers

* **Google Chrome** (latest version) — Recommended
* **Microsoft Edge** (latest version)
* **Mozilla Firefox** (latest version)
* **Safari** (latest version)

## Known issues

* **Internet Explorer** is not supported.
* **Older browser versions** may experience layout or functionality issues. Keep your browser updated for the best experience.
* **Mobile browsers** — Vissibl is optimised for desktop use. Some features may have limited functionality on mobile devices.

## Tips

* Enable JavaScript — Vissibl requires JavaScript to function.
* Allow cookies — Required for authentication and session management.
* Disable ad blockers on Vissibl if you experience any loading issues.
