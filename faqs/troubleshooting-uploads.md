# Troubleshooting Uploads

## Supported file formats

Vissibl accepts the following file types:

* PDF
* DOCX (Microsoft Word)
* XLSX (Microsoft Excel)
* CSV
* PPTX (Microsoft PowerPoint)

## My upload failed

* **Check the file format** — Make sure it's one of the supported types listed above.
* **Check the file size** — Very large files may take longer to process. Try splitting them if they're over 50MB.
* **Check your connection** — A stable internet connection is required for uploads.
* **Try again** — Occasional upload failures can happen. Wait a moment and retry.

## My document wasn't processed correctly

If metadata extraction or text parsing didn't work as expected:

* **Scanned PDFs** — If your PDF is a scanned image rather than searchable text, the extraction may be limited. Try re-scanning with OCR enabled.
* **Password-protected files** — Remove password protection before uploading.
* **Complex formatting** — Heavily formatted documents may not parse perfectly. The content will still be available, but some layout may be lost.

## I uploaded a document but it doesn't appear in the Vault

* Allow a few moments for processing — large files take longer.
* Refresh the page.
* If the file still doesn't appear, try uploading again or contact support.
