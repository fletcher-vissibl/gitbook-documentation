# Document Vault

Go to **Settings** > **Document Vault** to see all documents uploaded to your workspace.

This is a management view of your Vault. Each document shows:

* **File name** and type (PDF, DOCX, etc.).
* **Uploaded by.** Who uploaded the file.
* **Upload date.**
* **Sync status.** Whether the document has been processed and synced with Vissi's context (shown as a green "Synced" badge).

Use the **three-dot menu** on any document to manage it.

This is the same set of documents accessible through the **Vault** section in the main sidebar. The Settings view gives you a management overview of all files in one list.
