# User Management

Manage who has access to your Vissibl workspace and what they can do.

## Adding and removing users

1. Go to **Settings → User Management**.
2. Click **Add User** to invite someone new, or select an existing user to edit or remove them.
3. Removing a user revokes their access immediately.

## Roles & permissions explained

| Role | Access level |
| --- | --- |
| **Owner** | Full access including billing and account settings. |
| **Admin** | Full access to all modules and settings, except billing. |
| **Editor** | Can create, edit, and submit documents and records. Cannot publish or manage users. |
| **Viewer** | Read-only access to published documents and dashboards. |

## Resetting passwords

Admins and Owners can reset a user's password from the User Management screen. The user will receive an email with a secure reset link.
